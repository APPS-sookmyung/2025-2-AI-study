# 논문 리뷰 — _LLM-Generated Feedback Supports Learning If Learners Choose to Use It_

## 1) 연구 배경

- 피드백은 학습 효과를 크게 증진시키는 가장 강력한 방법 중 하나로 알려져 있다.
- 인간이 생성한 피드백에 대한 연구는 광범위하지만, 최근 등장한 거대 언어 모델(LLM), 특히 시나리오 기반 온라인 학습 환경에서 LLM이 생성하는 피드백의 학습 효과에 대한 연구는 상대적으로 부족하다.
- 효과적인 피드백은 시기, 유형, 과제 복잡성 등 여러 요인에 따라 달라지며, 특히 설명적 피드백(elaborated feedback)은 단순히 정오를 알려주는 것보다 학습에 더 큰 영향을 미친다.
- 기존 LLM 피드백 연구들은 ChatGPT를 활용한 힌트 제공이 인간 튜터와 유사한 학습 효과를 냈거나, 에세이 수정 점수와 동기 부여를 향상시켰음을 보여주었지만, 학습자의 실제 학습 효과와 인식을 깊이 있게 탐색한 연구는 드물다.
- 본 연구는 튜터 트레이닝이라는 독특한 맥락에서, 즉 튜터들이 학습자가 되어 개방형 응답에 대한 즉각적이고 설명적인 LLM 피드백을 받았을 때의 효과를 탐구합니다. 이는 수학 학습이나 글쓰기 능력 향상에 초점을 맞춘 기존 연구와 차별화된다.

---

## 2) 핵심 기여(Contributions)

- **LLM 피드백의 학습 효과 검증**: 885명의 튜터 학습자로부터 2,600개 이상의 레슨 완료 데이터를 분석하여, 온디맨드(on-demand) LLM-generated explanatory feedback이 튜터 학습에 미치는 영향을 RQ1 (학습 성과), RQ2 (효율성), RQ3 (학습자 인식) 측면에서 다각도로 조사했다.
- **선택 편향(Selection Bias) 조정**: LLM 피드백 사용 여부에 따른 잠재적 선택 편향(예: 원래 고성능 학습자가 LLM 피드백을 더 많이 사용할 가능성)을 해결하기 위해 **성향 점수(Propensity Scoring)**와 주요 계층화(Principal Stratification) 기법을 적용했습니다. 이를 통해 LLM 피드백의 순수한 학습 효과를 보다 정확하게 추정했다.
- **선택적 사용의 중요성 확인**: LLM 피드백을 사용하려는 경향이 높은 학습자(higher propensity)가 사후 테스트에서 유의미하게 높은 점수를 기록했으며, 선택 편향 조정 후에도 7개 레슨 중 2개 레슨에서 LLM 피드백이 학습에 통계적으로 유의미한(효과 크기 0.28, 0.33) 긍정적 효과를 보임을 입증했습니다. 이는 LLM 피드백의 효과가 학습자의 지원 요청 의지에 따라 달라진다는 중요한 함의를 제시한다.
- **효율성 및 긍정적 인식**: LLM 피드백이 레슨 완료 시간을 유의미하게 증가시키지 않았으며, 학습자들이 LLM 피드백을 압도적으로 '도움이 된다'고 평가(93.98%)하여, LLM 피드백이 비용 효율적이고 확장 가능한 학습 도구로서의 잠재력을 가짐을 시사한다.
- **재현성 높은 연구 자원 공개**: 연구 재현성을 높이기 위해 오픈 데이터셋, LLM 프롬프트, 채점 루브릭을 공개했다.

## 3) 아키텍처/방법론

### 3.1 연구 설계 및 조건

- **참가자**: 885명의 대학생 튜터가 7가지 시나리오 기반 튜터 훈련 레슨(예: 효과적인 칭찬, 오류 대응 등)을 완료했습니다. 총 2,648건의 레슨 완료 데이터가 수집되었다.
- **레슨 구조**: 수정된 predict-observe-explain 모델을 따르며, 튜터 학습자는 시나리오를 보고 개방형 응답 및 객관식 질문에 답변한다.
  - Q1(개방형 응답): 예측 단계. 여기에서 LLM 피드백 옵션이 제공된다.
  - Q5(연구 기반 권장 사항): 관찰 단계. 모든 그룹에 지연된 수정 피드백(delayed corrective feedback)이 제공된다.
  - Q7-Q10(사후 테스트): 아날로그 시나리오에 대한 예측 및 설명. LLM 피드백 없이 학습 성과를 측정한다.
- **조건 할당**:
  - Control (대조군): LLM 피드백에 접근할 수 없다.
  - Intent-to-Treat (ITT): LLM 피드백을 요청할 수 있는 옵션이 주어진다 (on-demand).
  - Treatment-on-the-Treated (TOT): ITT 그룹 중 실제로 LLM 피드백을 사용한 학습자 그룹이다.

### 3.2 LLM 피드백 생성

- **모델**: gpt-3.5-turbo 모델을 사용했다.
- **접근 방식**: few-shot prompting을 사용하여 모델을 훈련시켰다. 모델은 고품질 튜터 응답의 요소를 인식하고 일반적인 오개념을 식별하도록 프라이밍(priming)된다.
- **피드백 유형**: 설명적 피드백(explanatory feedback)으로, 연구 기반 튜터링 전략에 부합하는지 여부에 따라 응답을 '정확' 또는 '부정확'으로 분류한다. 부정확한 응답에 대해서는 약점을 식별하고, 연구에 부합하도록 재구성된(rephrased) 대안적 응답을 제공한다 (Fig. 2 참조). 모델은 원본 구조와 의도를 유지하면서 최소한의 수정만 하도록 명시적으로 지시받았다.

### 3.3 분석 계획

- **RQ1 (학습 성과)**:
  - TOT 분석: LLM 피드백을 실제로 받은 학습자(TOT)와 받지 않은 학습자(Control + ITT 중 미사용자) 간의 사후 테스트 성과 차이를 혼합 선형 모델(mixed linear model)로 분석했다.
  - ITT 분석 및 선택 편향 조정:
    - ITT 그룹 내에서 LLM 피드백 사용이 on-demand였기 때문에 발생하는 선택 편향을 제어하기 위해 **주요 계층화(Principal Stratification)**를 적용했다.
    - 학습자의 LLM 피드백 요청 경향(propensity)을 예측하기 위해 ElasticNet 회귀 모델을 사용했습니다. 이 모델은 일반적인 참여도, 응답 행동, 세션 특성 등 여러 특징을 활용하여 학습자가 LLM 피드백을 요청할 가능성을 예측했다.
    - 이 예측 모델을 대조군(Control)에 적용하여, LLM 피드백을 요청했을 가능성이 있는 대조군 학습자들을 가상의 비교 대상으로 설정하여 편향을 조정했다.
  - 상호작용 효과(Interaction Effect): 피드백 요청 경향과 조건 간의 상호작용을 테스트하여 LLM 피드백이 특정 경향을 가진 학습자에게 더 유익한지 평가했다.
- **RQ2 (효율성)**: LLM 피드백 수신 여부가 레슨 완료 시간에 미치는 영향을 로그 변환된 시간 데이터를 사용한 혼합 선형 모델로 분석했다.
- **RQ3 (학각자 인식)**: LLM 피드백에 대한 학습자들의 주관적인 평가(도움이 됨, 도움이 안 됨, 부정확함)를 분석했다.
- **사후 테스트 채점**: Q7과 Q9 (개방형 응답)은 GPT-4o를 사용하여 평가했다. 몇 차례의 프롬프트 개발 과정을 거쳐 문맥 프레이밍, 인간 채점 예시, CoT(Chain-of-Thought) 프롬프팅 등의 전략을 활용했다. 인간 평가자와의 상호 평가자 신뢰도(IRR)는 0.64-0.91 범위로 양호했다.

## 4) 결과

### 4.1 RQ1: LLM-Generated Feedback이 학습에 미치는 영향

- **초기 TOT 분석**: LLM 피드백을 받은 것이 사후 테스트 성과와 유의미하게 높은 연관성을 보였다 (효과 크기 0.10 SD, 95% CI [0.01, 0.19], p=.023). 개별 레슨별 효과 크기는 0.02에서 0.27 SD 범위였다.
- **선택 편향 조정 후 (ITT 및 Propensity Modeling)**:
  - LLM 피드백을 요청할 경향이 높은 대조군 학습자가 사후 테스트에서 더 높은 점수를 받는다는 유의미한 선택 효과가 관찰되었다 (베타 0.06, 95% CI [0.00, 0.12], p = .040).
  - ITT 조건과 요청 경향 간의 상호작용은 비유의적이었으나 (베타 0.04, 95% CI [-0.04, 0.12], p = .307), LLM 피드백에 참여한 학습자가 이득을 얻었음을 시사한다.
  - 개별 레슨별로 보면, 선택 편향을 조정한 후 "Giving Effective Praise" (베타 0.33)와 "Supporting a Growth Mindset" (베타 0.28) 두 레슨에서 작지만 통계적으로 유의미한(p < .05) 학습 이득이 발견되었다. 다른 레슨에서는 유의미한 효과가 없었다 (범위 -0.15 SD ~ 0.20 SD).
  - 단순히 LLM 피드백 옵션이 주어지는 것만으로는(ITT 주 효과) 사후 테스트 성과가 유의미하게 향상되지 않았다. 이는 실제로 LLM 피드백에 참여하는 것의 중요성을 강조한다.

### 4.2 RQ2: LLM 피드백이 레슨 효율성에 미치는 영향

- LLM 피드백 수신이 레슨 완료 시간에 통계적으로 유의미한 영향을 미치지 않았다 (추정치 0.00, 95% CI [-0.08, 0.08], p = .999). LLM 피드백을 받은 학습자가 평균 5.75분, 받지 않은 학습자가 평균 5.59분으로, 불과 9초 차이였다.
- 이는 LLM 피드백 제공이 학습 시간에 큰 부담을 주지 않는다는 것을 의미하며, 학습자들이 피드백을 통해 학습 유창성을 높였을 가능성을 시사한다.

### 4.3 RQ3: LLM-Generated Feedback에 대한 학습자 인식

- LLM 피드백에 대한 인식 조사에서, 332명의 응답자 중 대다수인 **312명 (93.98%)**이 피드백이 **"도움이 된다"**고 평가했다. "도움이 안 된다"는 14명(4.22%), "부정확하다"는 6명(1.81%)에 불과했다.
- 이러한 압도적인 긍정적 반응은 LLM-generated feedback에 대한 학습자들의 높은 수용도를 보여준다.

## 5) 결론의 해석 및 한계

### 5.1 해석

- **핵심 메시지**: LLM-generated feedback은 학습자들에게 유의미한 학습 이득을 제공할 수 있지만, 그 효과는 **학습자가 피드백을 적극적으로 찾고 활용하려는 의지(propensity to seek support)**에 달려 있다. 단순히 피드백을 제공하는 것만으로는 충분하지 않으며, 실제 참여가 중요하다.
- **실용적 가치**: 기존 피드백 시스템에 LLM 피드백을 추가하는 것은 낮은 비용과 높은 확장성을 가지며, 학습 시간을 크게 늘리지 않으면서도 학습 성과를 향상시킬 잠재력을 보여준다. 특히, 학습자들이 LLM 피드백을 매우 긍정적으로 인식한다는 점은 실제 교육 현장에서의 적용 가능성을 높인다.
- **정보량 증진**: LLM 피드백을 받은 학습자들이 사후 테스트에서 더 긴 응답을 작성했으며, 이는 피드백을 통해 학습 내용에 대한 더 깊은 이해나 유창성이 증가했을 가능성을 시사한다.

### 5.2 한계

- **선택 편향의 잔여 가능성**: 성향 점수 매칭 방법을 사용했음에도 불구하고, 모든 잠재적 교란 변수를 완벽하게 통제하지 못했을 수 있으므로 선택 편향이 완전히 제거되지 않았을 가능성이 있다.
- **API 실패 및 신뢰도**: OpenAI API 호출 실패율(15.7%)이 존재했으며, 이는 학습자들이 LLM 피드백에 대한 신뢰를 약화시켰을 수 있습니다.
- **피드백 처리 깊이**: LLM이 생성한 피드백이 다소 길었음에도 불구하고 완료 시간 증가가 없었던 것은, 모든 학습자가 피드백을 충분히 깊게 읽고 처리하지 않았을 가능성을 제기한다.
- **메타인지적 게으름(Metacognitive Laziness)**: Fan et al.의 연구에서 제기되었듯이, LLM 사용이 기술 의존성을 높여 학습자의 메타인지적 "게으름"을 유발할 수 있다. LLM 피드백을 받은 학습자가 LLM을 활용하여 사후 테스트 응답을 생성했을 가능성도 완전히 배제할 수 없다.

## 7) 향후 과제

- **피드백 활용 촉진 전략**: 학습자들이 LLM 피드백을 더욱 적극적으로 찾고, 읽고, 활용하도록 유도하는 적응형 도움 요청 지원(adaptive help-seeking support) 및 커리큘럼 기반 피드백 제공 전략에 대한 연구가 필요하다. 예를 들어, 특정 조건에서 LLM 피드백 요청을 의무화하거나, 피드백 활용도를 높이는 디자인 요소를 탐색할 수 있다.
- **피드백 처리 로그 분석**: 학습자들이 LLM 피드백을 읽는 데 보낸 시간, 건너뛴 부분 등을 상세히 분석하여 피드백 처리 깊이와 학습 성과 간의 관계를 규명할 필요가 있다.
- **지속 효과(Carryover Effects) 및 오용 방지**: LLM-generated response의 장기적인 학습 효과와 함께, 학습자가 LLM을 통해 생성된 피드백을 오용(예: 복사-붙여넣기)하는 경우를 탐지하고 방지하는 메커니즘을 연구해야 한다.
- **콘텐츠별 효과 이질성 분석**: 특정 레슨(예: 동기 부여 관련)에서 LLM 피드백의 효과가 더 강하게 나타난 이유를 심층적으로 분석하고, 내용 복잡성, 피드백 유형, 학습자의 선행 지식 등 다양한 요인과의 상호작용을 탐구해야 합니다. 특히, 형평성(equity) 관련 레슨에서 효과가 미미했던 이유에 대한 추가적인 조사가 필요하다.
- **LLM 프롬프트 및 평가 루브릭 고도화**: LLM 피드백의 질을 지속적으로 개선하고, 복잡한 교육 시나리오(예: 상호작용, 관계 추론)에 대한 LLM의 평가 및 피드백 생성 능력을 더욱 정교하게 만들 필요가 있다.

## 8) 총평

본 연구 "LLM-Generated Feedback Supports Learning If Learners Choose to Use It"는 LLM-generated explanatory feedback이 시나리오 기반 튜터 훈련에서 학습 성과를 향상시킬 수 있음을 보여주는 중요한 증거를 제시한다. 특히, 복잡한 선택 편향 문제를 해결하기 위한 정교한 방법론을 적용하여 그 효과가 학습자의 자발적인 참여 의지에 크게 좌우된다는 점을 밝혀냈다. 이는 LLM 기반 교육 시스템을 설계할 때 기술적 완성도뿐만 아니라 학습자 참여를 유도하는 pedagogical design의 중요성을 강조한다. 시간적 효율성과 학습자의 압도적인 긍정적 인식은 LLM 피드백이 교육 분야에서 저비용 고효율의 혁신적인 도구가 될 잠재력을 강력히 시사하며, 공개된 연구 자원들은 후속 연구의 발판이 될 것이다.
