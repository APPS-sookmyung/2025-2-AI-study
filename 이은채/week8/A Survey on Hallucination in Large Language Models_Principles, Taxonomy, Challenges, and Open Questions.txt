# A Survey on Hallucination in Large Language Models (Huang et al., 2023)

---

## 1. 정의
- Hallucination(환각) : 모델 출력이 사실 또는 입력 문맥과 불일치하는 현상
- 환각은 두 가지 기준으로 확인 가능함 : 
  - Factuality(사실성) : 외부 사실과 맞는지
  - Faithfulness(충실성) : 입력·문맥과 일치하는지 = 사용자가 준 사실과 맞는지
- LLM은 진실을 이해하는 것이 아니라 확률적으로 그럴듯한 다음 단어를 생성하기 때문에 환각이 구조적으로 발생함, 따라서 사실처럼 보이지만 틀린 정보인 환각 문제가 부각됨

---

## 2. 유형
### 2.1 사실 기반 오류(Factuality Hallucination)
- 사실과 다른 정보를 생성하는 오류  
  예: 서울은 중국의 수도다.

### 2.2 충실성 오류(Faithfulness Hallucination)
- 입력 문맥 또는 원문 내용과 어긋난 정보 생성  
  예: 원문에 없는 내용을 요약에 추가

### 2.3 논리/일관성 오류(Logical or Consistency Errors)
- 하나의 출력 내에서 논리적 모순이 발생  
  예: 그는 1980년에 태어나 1900년에 졸업했다.

### 2.4 근거/출처 오류(Grounding Errors)
- 존재하지 않는 출처, 링크, 논문, 사실을 지어서 만들어냄

### 2.5 형식 위반 오류(Format / Constraint Violations)
- 사용자 요청 형식(리스트, JSON 등)을 제대로 따르지 않음

---

## 3. 원인
### 3.1 데이터 원인
- 웹 크롤링 데이터의 오류·가짜 정보·편향을 그대로 배움
- 오래된 데이터만 학습해 최신 지식과 불일치
- 희귀 지식에 대한 학습 부족

### 3.2 모델 구조/학습 방식 원인
- 다음 단어 예측 기반 → 사실보다 문장 연결성에 집중
- 장기 기억/의존성 한계
- 확률적 성질 → 불확실성 구간에서 임의로 내용 생성

### 3.3 디코딩 전략 문제
- temperature, top-k, top-p 등이 환각 확률에 직접 영향
- 확률 분포가 애매한 경우 모델이 내용을 채워 넣음

### 3.4 외부 지식 부족
- 최신 정보나 전문 영역 지식 접근 불가
- 훈련 이후 발생한 사실은 “즉석 생성”으로 처리됨

### 3.5 프롬프트 문제
- 요구사항이 불명확 → 모델이 문맥을 추측하며 환각 증가

---

## 4. 탐지
### 4.1 자동 탐지(Auto Detection)
- 지식 그래프/검색 기반 fact-checking : 검색해 모델이 생성한 말이 진짜인지 확인
- 모델 출력의 불확실성(entropy) 기반 검출 : 엔트로피를 같이 출력
- 정답 기반 평가(BLEU, ROUGE 등) + 사실성 검증

### 4.2 인간 평가(Human Evaluation)
- 전문가가 직접 검증(의료/법률 등 고위험 분야) : 비용과 일관성 문제 존재

### 4.3 벤치마크 데이터셋
- TruthfulQA
- FActScore
- HallucinationBench
- HaluEval
- 여전히 표준화 부족

---

## 5. 해결
### 5.1 데이터 중심(Data-centric)
- 데이터 정제(노이즈 제거) : 잘못된 정보를 훈련 데이터에서 제거
- 고품질 지식/정답 보강 : 믿을만한 데이터 사용
- Instruction tuning(지시 학습), RLHF(사람 피드백 기반 강화학습) 활용

### 5.2 모델 중심(Model-centric)
- 사실성 강화 파인튜닝
- 모델 구조 개선
- 여러 출력 생성 후 교차 검증(Self-consistency)

### 5.3 추론(Inference) 단계 기반
- RAG (Retrieval-Augmented Generation) : 검색 + 생성 결합  
  → 가장 강력한 환각 해결 방법
- Self-checking : 모델이 스스로 자신의 답변 검증
- 외부 도구 사용 : 계산기, 브라우저, 위키 API 등 외부 도구 사용

---

## 6. 해결되지 않은 과제
- 환각 정의 자체가 표준화되지 않음  
- 벤치마크/평가 지표가 불완전함  
- 멀티모달 모델(MM-LLM)의 환각은 더 복잡  
- 모델이 최신 지식을 반영할 구조적 방법 부족  
- 실제 서비스 환경에서 실시간 사실 확인이 어려움  
- 의료/법률 등 고신뢰 분야는 “환각 0%”가 필수적이지만 현재 기술로 불가능  
- 환각은 LLM의 구조적 특성(확률 기반 언어 생성) 때문에 완전히 제거하기 어려움
